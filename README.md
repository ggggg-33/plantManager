# Система учета растений

## Описание проекта
**Система учета растений** — это программная система для управления коллекцией комнатных растений с функциями автоматизации ухода, диагностики заболеваний и планирования агротехнических мероприятий. Система реализована по многослойной архитектуре, обеспечивающей гибкость, масштабируемость и удобство сопровождения.

## Основные функции
- Учет растений с детальной информацией о состоянии  
- Автоматическая сезонная корректировка режима полива
- Диагностика заболеваний на основе симптоматики  
- Расчет оптимальных сроков пересадки на основе темпов роста
- Система уведомлений о необходимых мероприятиях по уходу
- Визуализация состояния растений через цветовые индикаторы
- Поддержка различных хранилищ данных: PostgreSQL, CSV
- Фильтрация и сортировка растений по различным параметрам
- Статистика коллекции растений

## Архитектура приложения

### 1. View (Слой представления)
- Графический интерфейс пользователя (`hello-view.fxml`)
- Обработка пользовательских действий и валидация ввода
- Контроллер (`Controller`) координирует взаимодействие между интерфейсом и сервисным слоем

### 2. Service (Слой сервисов)
- Валидация данных растений
- Управление операциями с растениями (добавление, редактирование, удаление)
- Координация специализированных операций (полив, пересадка, диагностика)
- Основной класс: `PlantService`

### 3. Business (Бизнес-слой)
- Бизнес-объекты: `Plant` (сущность растения)
- Прикладная логика: `PlantCareManager`
- Реализация бизнес-правил и алгоритмов
- Автоматическая сезонная корректировка полива
- Диагностика заболеваний и расчет сроков пересадки

### 4. Data Access (Слой доступа к данным)
- Интерфейс `PlantDao` абстрагирует работу с различными хранилищами
- Поддержка PostgreSQL и CSV форматов
- CRUD-операции с растениями
- Обеспечение целостности данных

## Основные сущности
- `Plant`: модель растения (id, name, plantingDate, wateringFrequency, lastWateringDate, lastRepottingDate, healthStatus, growthRate, currentHeight)

## Вспомогательные компоненты
- `PlantDao`: интерфейс доступа к данным
- `PlantCsvDao`, `PlantPostgresDao`: реализации DAO для различных хранилищ
- `PlantDaoFactory`: фабрика для создания экземпляров DAO
- `PlantService`: сервисный слой приложения
- `PlantCareManager`: менеджер ухода за растениями (уведомления, статистика)
- `Controller`: управление пользовательским интерфейсом

## Ключевые особенности

### Интеллектуальные алгоритмы
- **Сезонная корректировка полива**: автоматическое изменение частоты полива в зависимости от времени года
- **Диагностика заболеваний**: анализ симптомов и предоставление рекомендаций по лечению
- **Расчет пересадки**: определение оптимальных сроков пересадки на основе скорости роста растений
- **Система уведомлений**: своевременные напоминания о необходимых мероприятиях

### Гибкость хранения данных
- **CSV формат**: для простоты использования и переносимости
- **PostgreSQL**: для надежного хранения и производительности

## Преимущества архитектуры
1. **Четкое разделение ответственности** между слоями приложения
2. **Гибкость и масштабируемость** за счет модульной структуры
3. **Удобство тестирования** каждого компонента независимо
4. **Легкость расширения** функциональности

## Начало работы

### Установка и запуск
1. Клонируйте репозиторий проекта
2. Убедитесь, что установлены Java 17+ и Maven
3. Выполните команду: `mvn clean javafx:run`
4. Для работы с PostgreSQL предварительно настройте базу данных

### Использование
1. Выберите источник данных (CSV или PostgreSQL)
2. Добавьте растения через форму ввода
3. Отслеживайте уведомления о необходимых мероприятиях
4. Используйте функции полива, пересадки и диагностики
5. Анализируйте статистику коллекции
