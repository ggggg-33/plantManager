# Техническое задание: "Разработка программной системы для учета растений"

## 1. Введение

Настоящее техническое задание распространяется на разработку программного продукта «Система учета растений» для применения в сфере комнатного растениеводства и управления ботаническими коллекциями. Программа позволяет пользователю вести учет растений, автоматизировать процессы ухода, диагностировать заболевания и управлять пересадками с использованием различных источников хранения данных.

## 2. Основания для разработки

Программный продукт разрабатывается в соответствии с рабочей программой по дисциплине «Программная инженерия» направления подготовки «09.03.03 – Прикладная информатика в экономике цифрового общества» Воронежского государственного технического университета в ходе курсового проектирования по теме «Разработка программной системы для учета и анализа личных расходов».

## 3. Назначение разработки

Программный продукт предназначен для:
- Ведения учета коллекции комнатных растений
- Автоматизации контроля полива с сезонной корректировкой
- Диагностики заболеваний на основе симптоматики
- Управления графиком пересадок на основе темпов роста
- Хранения данных в различных источниках (CSV-файлы, PostgreSQL)
- Формирования уведомлений о необходимых мероприятиях по уходу

Пользователь может систематизировать уход за растениями, получать своевременные напоминания, диагностировать проблемы и принимать обоснованные решения по содержанию зеленой коллекции.

## 4. Требования к функциональным характеристикам программного продукта

### 4.1. Функциональные требования

| Идентификатор функционального требования | Описание |
|------------------------------------------|-----------|
| FUN-01 | Добавление нового растения с указанием названия, вида, даты посадки, высоты и частоты полива |
| FUN-02 | Редактирование параметров существующего растения |
| FUN-03 | Удаление растения из коллекции |
| FUN-04 | Автоматическая коррекция частоты полива по сезону (лето/зима) |
| FUN-05 | Диагностика заболеваний на основе описания симптомов |
| FUN-06 | Расчет необходимости пересадки на основе времени с последней пересадки |
| FUN-07 | Отметка о выполнении полива с обновлением даты последнего полива |
| FUN-08 | Отметка о выполнении пересадки с обновлением даты последней пересадки |
| FUN-09 | Фильтрация растений по названию, виду и статусу здоровья |
| FUN-10 | Сортировка растений по имени, высоте, дате посадки |
| FUN-11 | Формирование уведомлений о растениях, требующих полива или пересадки |
| FUN-12 | Просмотр статистики коллекции (общее количество, состояние растений) |

### 4.2. Требования к надежности

| Идентификатор требования надежности | Описание |
|-------------------------------------|-----------|
| REL-01 | Проверка корректности числовых параметров ввода перед сохранением |
| REL-02 | Валидация дат (дата не может быть в будущем) |
| REL-03 | Проверка целостности CSV-файла при загрузке данных |

**Требования к производительности:**

| Идентификатор требования производительности | Описание |
|---------------------------------------------|-----------|

| PER-02 | Обновление уведомлений должно выполняться при запуске приложения не более чем за 3 секунды |

**Требования к поддерживаемости:**

| Идентификатор требования поддерживаемости | Описание |

| SUP-02 | Модульная архитектура для легкого расширения функциональности |

### 4.4. Требования к составу и параметрам технических средств

**Минимальная конфигурация:**
- Тип процессора: Intel Core i3 или аналог
- Объем ОЗУ: 4 ГБ
- Пространство на диске: не менее 150 МБ
- ОС: Windows 10/11
- Java 17 или выше, JavaFX

### 4.5. Требования к информационной и программной совместимости

| Идентификатор требования к интерфейсам | Описание |

| INT-02 | Поддержка CSV-файлов |
| INT-03 | Интерфейс с пользователем должен быть реализован через JavaFX и FXML |

## 8. Порядок контроля и приемки

Испытание и проверка работы системы осуществляется на базе учебного класса. Тестирование проводится по следующим сценариям:
- Добавление растения и проверка отображения в таблице
- Проверка автоматической сезонной корректировки полива
- Тестирование диагностики заболеваний по симптомам
- Проверка формирования уведомлений о необходимых действиях
- Тестирование переключения между источниками данных (CSV/PostgreSQL)
- Проверка фильтрации и сортировки растений
- Валидация вводимых данных и обработка ошибок
- Тестирование расчета сроков пересадки
- Проверка обновления статусов после полива и пересадки
